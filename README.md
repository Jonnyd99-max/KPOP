# KPOP

A vibrant K-pop discovery web app for artist and member fact files, source-led buzz, and upcoming tour dates.

## Current prototype

- Search artists and individual members
- Browse group fact-file cards and fandom details
- Save favourite groups locally in the interface
- Scan editorial buzz and upcoming tour cards
- Responsive desktop and mobile design

The current content is representative prototype data. Tour dates and news should be connected to official, licensed, or otherwise verified sources before production use.

## Development

```bash
pnpm install
pnpm dev
```
